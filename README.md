# Homebrew tap

```sh
brew install --cask jewsh1r/tap/capslockswitcher
brew trust --cask jewsh1r/tap/capslockswitcher  # Homebrew 7+: keep `brew upgrade` loading it
```

| Cask | App |
| --- | --- |
| `capslockswitcher` | [CapsLockSwitcher](https://github.com/Jewsh1r/CapsLockSwitcher): Caps Lock switches between two keyboard layouts, and keeps working under Secure Input. |

The cask follows the app's GitHub releases automatically: `bump.yml` checks for a new release every 6 hours and updates the version and checksum.
